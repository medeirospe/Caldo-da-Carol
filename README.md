# Caldo da Carol 🍵

Página desenvolvida para apresentar o Caldo da Carol, divulgar o cardápio e facilitar os pedidos pelo WhatsApp. O visual utiliza cores quentes e elementos que remetem à comida caseira e ao cuidado no preparo.

Desenvolvi este projeto no início dos meus estudos em desenvolvimento web, com o objetivo de colocar em prática os conhecimentos de HTML e CSS. Ele registra essa etapa do meu aprendizado e recebe melhorias conforme avanço nos estudos.

## Funcionalidades

- Apresentação do Caldo da Carol.
- Cardápio com cinco sabores e uma descrição de cada um.
- Opções de **300 ml por R$ 15,00** e **500 ml por R$ 28,00**.
- Botões que abrem o WhatsApp com a mensagem “Olá, desejo pedir um caldo!”.
- Ajustes de layout para computador e celular.

O botão do Instagram está presente no rodapé. O link do perfil ainda precisa ser configurado.

## Tecnologias utilizadas

O projeto utiliza **HTML** para estruturar o conteúdo e **CSS** para definir a aparência e adaptar o layout a diferentes tamanhos de tela. Não utiliza frameworks nem exige instalação de dependências.

## Como visualizar

Para visualizar a página localmente, utilize a extensão **Live Server** no VS Code:

1. Baixe ou clone este repositório.
2. Abra a pasta **Caldo-da-Carol** no VS Code, incluindo as pastas `fontes` e `page_principal`.
3. Com a extensão Live Server instalada, clique com o botão direito em `page_principal/index.html` e escolha **Open with Live Server**.
4. A página será aberta no navegador.

Abra o projeto pela pasta principal para que as imagens, fontes e estilos sejam carregados corretamente.

## Aprendizados

O desenvolvimento permitiu praticar a estruturação de páginas com HTML, a organização de elementos com Flexbox e o uso de media queries para adaptar o layout a telas menores. Também trabalhei o alinhamento dos cards, a combinação de cores e a padronização dos botões.

O foco está em aplicar os fundamentos do desenvolvimento web em uma página simples e funcional, mantendo espaço para melhorias futuras.
